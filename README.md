ESTARA — Real Estate Website

Industry: Real Estate / Property Management
Objective: A premium real-estate website designed to help users discover, compare, and enquire about thoughtfully selected properties across Bengaluru. The website combines a clean editorial aesthetic with subtle 3D interactions to create a modern and sophisticated property-browsing experience.

Live Demo: [https://estara-vert.vercel.app/](https://estara-vert.vercel.app/)

Technologies Used

HTML5 — Structures the website and its sections.
CSS3 — Handles styling, layouts, responsive design, animations, and 3D hover effects.
JavaScript — Adds interactivity such as property search, rental slider, favourite buttons, mobile menu, and form handling.
Google Fonts — Provides elegant and modern typography.
CSS Grid & Flexbox — Creates flexible and responsive layouts.
CSS 3D Transforms — Adds subtle depth and interactive 3D effects.
Responsive Web Design — Ensures the website works smoothly on desktop, tablet, and mobile devices.

Website Sections

Header & Navigation — ESTARA logo, navigation links, and Enquire Now CTA.
Hero Section — Introduces ESTARA with the tagline “Discover. Choose. Belong.”and property-focused CTAs.
Property Search — Helps users search based on Buy, Rent, Sell, location, property type, and budget.
Featured Properties — Displays selected properties with pricing, location, and specifications.
Property Categories — Organizes listings into Villas, Apartments, Houses, and Commercial properties.
Rental Properties — Provides a horizontal slider to explore rental homes.
Why Choose ESTARA — Highlights curated listings, local expertise, reliable information, and personal assistance.
Locations — Showcases popular Bengaluru areas such as Whitefield, Indiranagar, and Koramangala.
Agents — Introduces property consultants for personalized assistance.
Testimonials — Displays customer feedback to build trust.
Enquiry Form — Allows users to enquire about buying, renting, selling, or investing.
Footer— Includes contact/navigation information, ESTARA branding, and creator credit.

File Description

`index.html`
Contains the complete ESTARA website structure, including navigation, hero section, property search, featured properties, property categories, rental properties, Bengaluru locations, agents, testimonials, enquiry section, and footer.

`style.css`
Contains the complete visual design system — ESTARA colour palette, typography, responsive layouts, property cards, rental slider styling, animations, hover effects, subtle 3D effects, buttons, forms, and mobile adaptations.

`script.js`
Contains the website's JavaScript functionality — hero text animation, property interactions, Buy/Rent/Sell selection, rental slider, favourite buttons, location interactions, mobile menu, enquiry form handling, scroll interactions, and 3D UI effects.

`assets/logo/estara-logo.png`
ESTARA brand logo used throughout the website, including the navigation, hero section, and footer.

`assets/`
Contains the property, rental, location, agent, and other visual images used throughout the ESTARA website.

`README.md`
Contains project documentation, including the ESTARA concept, features, website sections, design choices, technologies used, file structure, and future improvements.

How to Run

Open `index.html` directly in any modern browser, or serve the folder locally:

```bash
npx serve .
```
You can also use VS Code Live Server:

Open the project folder in VS Code.
Install the Live Server extension.
Right-click `index.html`.
Select Open with Live Server.
The website will open in your browser.

No build step, no dependencies, and no external JS libraries — everything is plain HTML/CSS/JS plus Google Fonts loaded via CDN.

Notes on Design Choices

The ESTARA website uses a modern luxury real-estate design with a green, cream, white, and muted-gold colour palette. Elegant typography and premium property imagery create a sophisticated look, while subtle 3D effects, animations, shadows, and smooth transitions add interactivity. The responsive layout ensures a clean and user-friendly experience across all devices.
